# CyberBrain v0.3.0 — Closed-Loop Cognition & Bounded Reasoning

> Historical release record. Current operational behavior is documented in `docs/CURRENT_RUNTIME.md` and canonical specs.

This minor release completes the C1–C5 completion program milestones, establishing closed-loop continual learning and bounded reasoning over typed relations.

Key changes:

- **C1 Cognitive Event Loop:**
  - Integrated `UniversalAgentAdapter` with `PredictionPolicy` and prospective action/outcome capture (`record_prediction`, `resolve_prediction`).
  - Added correlation ID tracking and idempotent prediction persistence in `PredictionLearningService`.
  - Added deterministic `CognitiveHeartbeat` executive loop for open work inspection and calibration auditing without generative monologue.

- **C2 Review Scalability & Stopword Hygiene:**
  - Fixed structural D1 writeback defect (`missing_or_ambiguous_domain`) across episodic-sourced candidates, enabling manual domain override and default fallback.
  - Implemented in-run candidate duplicate collapse in `DreamEvidenceGate` via text fingerprints.
  - Expanded `_DEFAULT_STOPWORDS` to filter functional English stopwords, preventing stopword-polluted entity names (`and_*`, `the_*`).
  - Added `project` scoping filter to `pending_reviews` and `dream_reviews` tool.

- **C3 Retrieval Closure:**
  - Re-benchmarked and formalized default retrieval policy as vector retrieval with explicit foreground opt-ins for `literal` and `hybrid` modes.
  - Retired shadow observation dependencies from canonical retrieval path.

- **C4 Integrated Cognitive Acceptance:**
  - Validated M3 Salience, M4 Concept Formation, M5 Working Memory, M6 Self-Model, and M7 Memory Lifecycle end-to-end integration scenarios.
  - Verified M6 fail-closed readiness gates and M7 reversible access-tracking updates.

- **C5 Bounded Reasoning Layer:**
  - Added `cyberbrain.reasoning` module with `BoundedReasoningEngine`.
  - Implemented deterministic contradiction detection (polarity mismatch, structural conflict, causal cycles).
  - Implemented typed inference rules (symmetric contradiction, transitive dependency) with explicit premise provenance and non-canonical `proposed` status.
  - Implemented `evaluate_counterfactual` sandbox for isolated hypothetical scenario evaluation without storage mutation.

- **Version Bump:**
  - Version authority bumped to `0.3.0` in `cyberbrain/_version.py`.
