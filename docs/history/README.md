# Historical Documentation

Files in this directory are preserved development, migration, cutover, benchmark, or runtime
snapshots from earlier CyberBrain phases.

They are non-normative.

Do not copy historical values such as record counts, collection names, service slots, acceptance
windows, benchmark totals, deployment paths, or rollback instructions into a current deployment
without independently verifying them.

Current project guidance lives in:

- ../../README.md
- ../../PLAN.md
- ../../TOOL_GUIDE.md
- ../CURRENT_RUNTIME.md
- ../DREAMING_ROUTING.md
- ../../specs/

Historical documents intentionally retain the facts and terminology that were true at the time they
were written. A stale number inside this directory is not a documentation bug if it is clearly part
of the historical record.
