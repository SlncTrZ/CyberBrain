# CyberBrain v0.2.1 — Active M3–M7 Runtime Integration

> Historical release record. Current operational behavior is documented in `docs/CURRENT_RUNTIME.md` and `specs/COGNITIVE_RUNTIME_PATH.md`.

This patch release activates the previously source-complete M3–M7 mechanisms in the normal authenticated MCP/coding-agent path while preserving schema V2 and API compatibility.

Key changes:

- M3 Salience actively scores/reorders an already-authorized vector prefetch;
- M4 Concept discovery/registry runs over bounded same-scope recall/store evidence;
- M5 Working Memory actively selects bounded scope/session/task context and reserves M4/M6 advisory capacity;
- M6 runs after trusted Prediction→Outcome resolution and automatically accepts/persists only after the existing trusted readiness gate passes;
- M6 strategy hypotheses additionally require multi-session support, and metadata/evidence revisions evolve even when claim text stays unchanged;
- M7 records access and performs reversible event-driven suppression/reactivation on touched/prefetched records;
- there is no automatic full historical M7 sweep;
- canonical and legacy MCP operations use the same coordinator;
- optional transient `context_session_id` / `task_id` hints remain backward-compatible;
- kill switches allow M3–M7, M6 auto-accept, and M7 actuation to be disabled independently at runtime.

The release does not enable `agent_ready` or `multi_user`; existing P3 fail-closed boundaries remain in force.
